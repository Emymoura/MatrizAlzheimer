# MatrizAlzheimer
Os dados de expressão gênica foram filtrados para manter apenas genes com cobertura ≥80% em cada estudo. Em seguida, foram selecionados apenas genes comuns a todos os datasets. A expressão gênica foi normalizada por Z-score gene-a-gene dentro de cada estudo, garantindo comparabilidade entre diferentes plataformas experimentais. Os metadados clínicos foram preservados sem transformação. Por fim, os estudos foram concatenados verticalmente, resultando em um dataset integrado multi-estudo.
foram usados os estudos: GSE33000, GSE26927, GSE29378 e GSE37263
